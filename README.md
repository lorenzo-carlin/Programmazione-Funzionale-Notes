# 💻 Programmazione Funzionale — Appunti & Laboratori

Appunti ed esercizi del corso di **Programmazione Funzionale** (A.A. 2025/2026).

Questa repository raccoglie una rielaborazione personale degli argomenti trattati a lezione e gli esercizi pratici di laboratorio, pensata come supporto allo studio e alla preparazione dell'esame.

## 📖 Dispensa Completa

📄 **[Visualizza / Scarica la dispensa in PDF](./Dispensa.pdf)**

La dispensa è una versione compilata degli appunti (ultimo aggiornamento: 18 giugno 2026). Le pagine Markdown in `lezioni/` sono la fonte più aggiornata.

## 🗂️ Struttura della Repository

```text
.
├── README.md             # Indice principale e guida alla navigazione
├── AGENTS.md             # Istruzioni per gli agenti che lavorano sulla repo
├── ROADMAP.md            # Piano di evoluzione della repository
├── Dispensa.pdf          # Dispensa completa del corso
└── lezioni/              # Appunti teorici e laboratori, numerati per lezione
    ├── lezione-01.md
    ├── 02. Type system, errori, variabili e funzioni.md
    ├── 03. Laboratorio 1.md
    └── ...
```

La numerazione segue l'ordine delle lezioni del corso: da `03` in poi i numeri dispari sono laboratori e i pari teoria, con l'eccezione del `07`, che contiene anche la prima parte del pattern matching.

## 💡 Come Navigare la Repo

- **Dispensa Unica:** puoi consultare l'intero corso stampabile/offline scaricando la [`Dispensa.pdf`](./Dispensa.pdf).
- **Pagine dedicate:** clicca sui link `Leggi →` o `Apri →` per studiare un singolo argomento o vedere il codice dei laboratori.
- **Ritorno rapido:** la pagina introduttiva contiene un link per tornare a questo indice; per le altre pagine puoi usare la navigazione del repository o il pulsante Indietro del browser.
